**Objetivo:**  
El presente repositorio tiene como objetivo recopilar, organizar y documentar el desarrollo de nuestro proyecto final, realizado durante la asignatura de Computación Gráfica e Interacción Humano-Computadora.
A lo largo del repositorio se integrarán los códigos fuente, modelos 3D, imágenes, capturas de resultados y demás recursos utilizados durante las diferentes etapas del proyecto, principalmente mediante C++ y OpenGL.

Asimismo, este espacio permitirá mantener un registro ordenado del proceso y desarrollo de los diferentes elementos que conforman el proyecto final.
